# План: мастер настройки VPS и выпуск 2026.11.01

Пользователь согласовал сценарий и поручил реализацию и публикацию на GitHub.

1. Проверить выбранные шаги и реализовать команды подготовки пользователя с тестами. Не выполнять пропущенные изменения.
2. Реализовать транзакционное изменение SSH: исходные копии, независимый откат, проверка эффективных параметров, подтверждение новым соединением. Проверить в изолированной shell-песочнице.
3. Подключить единый мастер к добавлению, карточке и действиям; сохранять отдельное подключение и удалять исходное только после проверки и подтверждения.
4. Обновить переводы, документацию, версию и встроенный Python в Nix; проверить полную suite и вычисление Nix.
5. Проверить diff на безопасность, создать коммиты и тег, отправить на GitHub, проверить CI; создать GitHub release при наличии авторизации API.

Риски: потеря SSH-доступа, частичное выполнение, перезапись исходного подключения. Защита: новая проверка входа перед ограничениями, откат под root, исходная запись сохраняется по умолчанию. Реальный VPS и Android без разрешения не трогаем. Секреты GitHub не читаем и не публикуем.
